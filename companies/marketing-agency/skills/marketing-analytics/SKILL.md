# Marketing Analytics Skill

## Purpose

Provides marketing agents with the ability to collect, analyze, and report
on marketing performance data across all channels.

## Capabilities

### Web Analytics
- Parse and analyze web traffic data (pageviews, sessions, bounce rate, time on site)
- Track conversion funnels and identify drop-off points
- Analyze traffic sources and attribution
- Monitor Core Web Vitals and site performance

### Social Media Analytics
- Aggregate engagement metrics across platforms
- Calculate engagement rates, reach, and impressions
- Track follower growth and audience demographics
- Identify top-performing content by platform

### Ad Performance Analytics
- Track campaign metrics: CPC, CPM, CTR, CPA, ROAS
- Analyze A/B test results with statistical significance
- Monitor budget pacing and spend efficiency
- Cross-channel attribution analysis

### SEO Analytics
- Track keyword rankings over time
- Monitor organic traffic trends
- Analyze backlink profile changes
- Content performance by search intent category

### Reporting
- Generate weekly/monthly marketing performance summaries
- Create data visualizations for dashboards
- Produce executive-level marketing reports for board review
- Highlight anomalies, trends, and actionable insights

## Usage

Agents using this skill should:

1. Specify the data source and time range for analysis
2. Define the metrics and KPIs to track
3. Request the appropriate report format (summary, detailed, dashboard)
4. Include comparison periods where relevant (week-over-week, month-over-month)
